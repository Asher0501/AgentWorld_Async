# Product

## Register

product

## Users

AI/LLM researchers and game developers building autonomous multi-agent simulations. They are technically sophisticated, familiar with LLMs and Python, and value architectural elegance over feature bloat. They want to define agent behavior declaratively — not through imperative code.

## Product Purpose

AgentWorld Async is an LLM agent simulation engine built on a single radical claim: **the engine is a body-plan for LLM cognition.** It provides a universal sensory interface (channels) that reports physical facts. The LLM provides all cognition. Zero Python code crosses into cognitive territory.

The engine scales across worlds — Witcher taverns, Friends coffee shops, 25-agent villages — by swapping YAML config files. The Python never changes.

## Brand Personality

- **Rigorous**: Every architectural decision is traceable to first principles
- **Deleted**: The direction is always removal, never addition
- **Honest**: The engine never fabricates, judges, or names the world

## Anti-references

- NOT Generative Agents (730 lines of cognitive Python)
- NOT AutoGen (message-bus orchestration)
- NOT scripted NPC behavior trees
- NOT "prompt engineering" — every prompt is composed from YAML slots

## Design Principles

1. **Engine reports facts, LLM provides cognition** — The non-negotiable boundary
2. **Channel as sensory interface** — YAML `fields:` list = perceptual bandwidth
3. **Delete, don't add** — Every removal returns sovereignty to the LLM
4. **Definition separate from implementation** — Hook points in engine, implementations outside
5. **Silence is a valid state** — The engine never fabricates content

## Accessibility & Inclusion

WCAG not applicable (terminal/API tool). Dark theme preferred for all generated UI artifacts.

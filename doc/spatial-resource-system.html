1. The Paradigm Shift 范式转换

Accounting Model · 会计

Resources are numbers in a ledger. Ownership is a mapping from entity→integer. Transfer is arithmetic. The engine tracks balances.

Physics Model · 物理

Resources are objects in space with position, quantity, and visibility radius. Ownership is implicit in position. Transfer is movement. The engine tracks spatial state.

Singleton Registry · 类单例

One class per interchangeable resource type. GoldCoin maintains ONE spatial registry for ALL gold coins in the world. Fungible items share a registry; unique items are individual entities.

Radius = Permission · 半径=权限

radius=0: in pocket (carried, invisible). radius=1: in hand (visible, transferable). radius=5: on ground (visible to all nearby). Visibility by radius — no separate permission system.

4. Constraint System 约束系统

Constraints are atomic, stateless physical laws. Each constraint declares its activation condition, timing group, and provides validate() + apply() methods.

4.2 Example: qty_non_negative 示例：数量非负约束

@register("qty_non_negative")
class QtyNonNegativeConstraint(Constraint):
    timing = "pre"

    def activation(self, entities, action_def):
        # 触发条件: action 里声明了 resource_type
        return "resource_type" in action_def

    def validate(self, entities, action_def, world):
        res = get_resource(action_def["resource_type"])
        pos = action_def.get("from_pos", entities[0].pos)
        need = action_def.get("qty", 1)
        have = res.qty_at(pos)
        ok = have >= need
        reason = f"{res.name}: need {need}, have {have}" if not ok else ""
        return ok, reason

    def apply(self, entities, action_def, world):
        pass   # qty check is a gate — no execution needed
引擎循环 / Engine Loop: constraints.process(entities, action_def, world) — groups active constraints by timing (pre/exec/post), calls validate() then apply() for each group. If any pre constraint fails → stops, returns failure info. LLM perceives failure next tick and re-decides. No retry, no pending, no two-phase. Single pass, result-driven.

5. Action Interfaces 动作接口

Action interfaces decouple interaction flow from constraint logic. The engine dispatches by action type name. The interface manages its own lifecycle (consent, direct, exchange) independently.

5.1 Consent Interface 同意接口

class ConsentInterface(ActionInterface):
    def execute(self, agent, target, action_def, decision, world):
        if decision.get("consent_action") == "propose":
            # 提议阶段 — 存入 target._pending_actions, 不执行约束
            target.get("agent")._pending_actions.append(decision)
            return ProcessResult(status="proposed")

        elif decision.get("consent_action") == "accept":
            # 确认阶段 — 触发约束, 原子执行
            return constraints.process([agent, target], action_def, world)

        elif decision.get("consent_action") == "reject":
            clear_pending(target, decision["consent_id"])
            return ProcessResult(status="rejected")

5.2 Direct Interface 直接接口

class DirectInterface(ActionInterface):
    def execute(self, agent, target, action_def, decision, world):
        # 直接执行 — 立即触发约束
        return constraints.process([agent, target], action_def, world)

9. Design Philosophy Alignment 设计哲学对齐

Physics is the ledger · 物理即账本

Gold in space has position, quantity, radius — no account balance needed. Conservation is guaranteed because objects cannot be in two places at once. The engine is a physics simulator, not an accountant.

Action interfaces are the contract · 动作接口即合约

Each entity declares its own actions. Each action binds its own constraints. B observes A's actions through sensory channels — no coupling, no protocol, no two-phase pending.

Constraints are independent atoms · 约束即独立原子

Each constraint is a self-contained physical law: activation, timing, validate, apply. The engine groups them by timing and loops. No constraint knows about any other constraint.

Radius is permission · 半径即权限

radius=0: invisible. radius=1: visible, transferable. radius=5: visible, ground-level. No separate access control or permission system — spatial physics defines what's possible.

Closed loop with natural feedback · 闭环自然反馈

Constraint failure → entity perceives unchanged state → LLM re-decides. No retry loop, no pending, no engine-managed state. The feedback loop is closed by spatial reality — not by software protocol.

Fungible ≠ unique — both are first-class · 可互换与唯一并存

Fungible resources use singleton spatial registries. Unique items are individual entities. Both appear in sensory channels through the same engine interface — zero dispatch branching.

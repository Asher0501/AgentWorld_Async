1. Everything is a Spatial Object 万物皆空间物体

唯一的区别: Class Singleton 用一张 _registry 字典存位置→数量。Entity 用自己的 .pos 属性存位置。move() 在 Class Singleton 里改字典条目，在 Entity 里改属性。qty_at(pos) 在 Class Singleton 里查字典返回数量，在 Entity 里返回 1 或 0。除此之外——接口完全一致。

2. Sensory Channel — One Perception for Everything 感官统一

3. Constraint System 约束系统

引擎只有一行调用。约束自己决定触发条件、触发时机、如何校验。

约束对 Class Singleton 和 Entity 同样处理: qty_at(pos) 对 gold 查字典返回 50，对 sword 返回 1 或 0。move(from, to) 对 gold 改两条字典条目，对 sword 改一个属性。约束代码完全一致——不需要知道对象是什么类型。

5. Extending the System 扩展系统

+New Spatial Object

Add a class in core/spatial/: 20 lines. Inherit SpatialObject. Choose class_singleton or entity. Register in YAML. Zero engine changes.

+New Constraint

Add a class in core/constraints/: 25 lines. @register("name"). Declare timing, activation(), validate(), apply(). Zero engine changes.

+New Action

Add key to entity's interact: block in YAML. Bind constraints by name. Zero Python changes.

+New World

Create new YAML file. Declare entities, resources, constraints. Same engine drives any world. Zero engine changes.

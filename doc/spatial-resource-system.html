1. Core Principles 核心原则

① 物品是被动的 · Items are passive

物品只知道自己的空间状态——qty_at(x,y)、radius_at(x,y)、move(from,to,qty,r)。没有 owner、没有 transfer、没有 belongs_to。只能被移动 — 不知道谁在移动它。

② NPC 是主动的 · NPCs are active

NPC 决定移动什么。所有输入参数都是纯坐标。Geralt 把金币从 (12,7) 移到 (12,8)，Rachel 从 (12,8) 移到 (14,9)。引擎不知道"交易"——只知道两次 move()。

③ 约束即物理 · Constraints = physics

约束校验物理可行性：那个位置有足够的数量吗？耐久够吗？冷却好了吗？约束不判断"谁的金币"、"交易是否公平"。只判断物理可行性。

④ 归属 = LLM 推断 · Ownership = LLM inference

引擎不记录"金币属于 Geralt"。引擎只报告金币在某个坐标。LLM 从 sensory 看到"金币在 Geralt 身旁"——自己推断归属。

⑤ 半径即权限 · Radius = permission

radius=0: sensory 不可见——LLM 根本不知道存在——不可能 move。radius=1: 可见、可交互——LLM 自己决定要不要尝试。不需要额外的 access control 约束。

2. System Architecture 系统架构

3. Spatial Object Interface 空间物体接口

一切物体实现同一接口。参数全是纯坐标——物品不知道谁调用自己。

move(from, to, qty, radius)

从坐标 A 移到坐标 B。参数全是 (x,y)。
物品不知道 from 是谁的口袋、to 是谁的手。

qty_at(x, y) → int

该坐标有多少。对于 entity — 如果自身在此位置则返回 1，否则 0。对于 class singleton — 查注册表返回数量。

radius_at(x, y) → int

该坐标堆叠的可见半径。0=隐形, 1=近处, ≥5=远处可见。

all_near(x, y, r) → list

中心坐标半径内的所有堆叠。供感官系统渲染。
跳过 radius=0 的条目——口袋里的东西不可见。

4. Constraint System 约束系统

每个约束是一个自包含的物理定律。引擎只知 timing 和 activate()/validate()/apply()。

# 引擎一行调用。Zero domain knowledge.
constraints.process(entities, action_def, world)

# 模块内部 — 按 timing 分组，逐个 validate + apply
def process(entities, action_def, world):
    active = [c for c in ALL if c.activation(entities, action_def)]
    for group in ["pre", "exec", "post"]:
        for c in group_by(active, group):
            ok, reason = c.validate(entities, action_def, world)
            if not ok: return Result(failed=c, reason=reason)
            c.apply(entities, action_def, world)
    return Result(ok=True)

# 引擎不知道任何约束名 · 不知道 gold 是什么 · 不知道 "consent" 是什么

activation() — 我该上班吗？

双方都在 action 里声明了这个约束 → 激活。只有一方 → 不触发。引擎不参与判断。

timing — 我在哪个阶段？

pre = 执行前 · exec = 执行中 · post = 执行后。约束自己声明——引擎只分组。

validate() — 现在能行吗？

返回 (bool, reason)。不通过 → 引擎停止。LLM 下轮感知失败原因。

apply() — 执行

只在 validate 通过后调用。原子操作——一次完成。无状态残留。

新增约束: 三步——写一个 25 行的 class + @register("name") 装饰器 + 在 YAML 某个 action 的 constraints: 列表里声明。引擎零改动。约束自己决定一切。

AgentWorld Async — 前端模块架构

数据监控（网管风格）· 像素前端（AI Town 风格）· 引擎解耦 · 内部插件化
两个模块独立存在、独立删除、互不依赖

一、架构概览

⚙ Engine

只 push 事件到 EventBus。不知道谁在听。不依赖任何前端代码。

📡 EventBus

WebSocket 广播中心。Dashboard 和 Visual 共享同一个 emitter。

📊 Dashboard

网管风格数据面板。内部 Panel 插件系统——增删面板只需改一行注册。

🎮 Visual

AI Town 风格像素前端。内部 Layer 图层系统——增减图层只需改一行注册。

二、模块隔离策略

引擎耦合面：只有 src/event_bus.py 的 import 和 event_emit() 调用。
删掉 Dashboard + Visual → 删除 commands.py 里两行 import + 两行 create_task。
删掉 event_bus → loop.py 的 event_emit 参数传 None（已有 None 检查）。零崩溃。

三、EventBus — 共享事件总线

路径迁移：dashboard/emitter.py → src/event_bus.py。类名 DashboardEmitter → EventBus。所有 import 同步更新。

四、共享基础设施 — frontend_shared/

Dashboard 和 Visual 的 server 代码完全相同——aiohttp + WebSocket 握手 + Director REST 端点。抽取到一个位置，两个模块各自 3 行 wrapper。

五、Dashboard — 网管风格数据监控

布局设计

设计原则：暗色底 + 等宽字体 + 高密度数据 + 无动画（纯数据刷新）。
和 htop / Grafana / ntop 同等风格——管理员看一眼就知道系统状态。

六、Visual — AI Town 风格像素前端

布局设计

设计原则：PixiJS 渲染引擎 + 多层 Container 叠加 + 顶部 HUD bar。
对标 AI Town 的像素画面——角色在地图上移动，对话气泡实时浮现。

Layer 图层系统

// visual/static/index.html 中的注册区:
//
// layers 列表 = 全部图层。删掉一个 = 对应视觉元素消失。

import { TilemapLayer }        from './layers/tilemap.js';
import { EntitiesLayer }       from './layers/entities.js';
import { DialogueBubblesLayer } from './layers/dialogue_bubbles.js';
import { HudLayer }            from './layers/hud.js';

const layers = [
  TilemapLayer,           // 删掉 → 底板消失
  EntitiesLayer,          // 删掉 → 角色/物品消失
  DialogueBubblesLayer,   // 删掉 → 对话气泡消失
  HudLayer,               // 删掉 → HUD 消失
  // 加一行 → 新视觉效果
];

function init(app) {
  layers.forEach(l => l.init(app));   // 各自创建 PIXI.Container
}
function update(event) {
  layers.forEach(l => l.update && l.update(event));
}

每个 Layer 的约定接口

const EntitiesLayer = {
  id: "entities",
  init(app) {
    this.agents   = new PIXI.Container();   // 角色圆点
    this.items    = new PIXI.Container();   // 物品方块
    this.gates    = new PIXI.Container();   // 门标记
    app.stage.addChild(this.agents);
    app.stage.addChild(this.items);
    app.stage.addChild(this.gates);
  },
  update(event) {
    // event.entities → 循环更新每个 sprite 的 x, y
    for (const e of event.entities) {
      const sprite = this.sprites[e.id];
      sprite.x = e.pos[0] * TILE_SIZE;
      sprite.y = e.pos[1] * TILE_SIZE;
    }
  },
  destroy() {
    this.agents.destroy();
    this.items.destroy();
    this.gates.destroy();
  },
};

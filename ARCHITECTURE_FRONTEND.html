AgentWorld Async — 前端模块架构

数据监控（网管风格）· 像素前端（AI Town 风格）· 引擎解耦 · 内部插件化
两个模块独立存在、独立删除、互不依赖

一、架构概览

⚙ Engine

只 push 事件到 EventBus。不知道谁在听。不依赖任何前端代码。

📡 EventBus

WebSocket 广播中心。Dashboard 和 Visual 共享同一个 emitter。

📊 Dashboard

网管风格数据面板。内部 Panel 插件系统——增删面板只需改一行注册。

🎮 Visual

AI Town 风格像素前端。内部 Layer 图层系统——增减图层只需改一行注册。

二、模块隔离策略

删掉 Dashboard + Visual → 删除 commands.py 里两行 import + 两行 create_task。
删掉 event_bus → loop.py 的 event_emit 参数传 None（已有 None 检查）。零崩溃。

六、Visual — 声明式像素前端

复用 slot 架构的核心理念——声明式 YAML + 通用转换器。换世界观 = 换 visual.yaml。不写一行 JS。

声明式渲染管线

核心思想：和 14 个 YAML slot 替代 730 行认知代码完全一致。
世界数据 (world.yaml) + 视觉配置 (visual.yaml) → 通用转换器 (generic_renderer.js) → PixiJS 画布。
换世界 = 换两行 YAML。不写一行 JS。

Layer 图层系统

// visual/static/index.html 中的注册区:
//
// layers 列表 = 全部图层。generic_renderer 读 visual.yaml 配置每个图层的样式。

import { TilemapLayer }        from './layers/tilemap.js';
import { EntitiesLayer }       from './layers/entities.js';
import { DialogueBubblesLayer } from './layers/dialogue_bubbles.js';
import { HudLayer }            from './layers/hud.js';

const layers = [
  TilemapLayer,           // 底板 — 从 visual.yaml tilemaps 读 tileset
  EntitiesLayer,          // 角色/物品 — 从 visual.yaml sprites 读精灵帧
  DialogueBubblesLayer,   // 对话气泡 — 从 visual.yaml dialogue 读样式
  HudLayer,               // HUD
];

function init(app, visualCfg, worldCfg) {
  layers.forEach(l => l.init(app, visualCfg, worldCfg));
}
function update(event) {
  layers.forEach(l => l.update && l.update(event));
}

每个 Layer 的约定接口

const EntitiesLayer = {
  id: "entities",
  init(app, visualCfg, worldCfg) {
    this.sprites = {};
    this.agents   = new PIXI.Container();
    this.items    = new PIXI.Container();
    this.gates    = new PIXI.Container();
    app.stage.addChild(this.agents);
    app.stage.addChild(this.items);
    app.stage.addChild(this.gates);
    // 从 visualCfg 加载精灵：
    //   visualCfg.sprites[entityId] → sheet URL + frame → PIXI.Sprite
    //   没找到 sprites → fallback 到 visualCfg.colors[name] → 彩色圆点
  },
  update(event) {
    for (const e of event.entities) {
      const s = this.sprites[e.id];
      s.x = e.pos[0] * TILE_SIZE;
      s.y = e.pos[1] * TILE_SIZE;
    }
  },
  destroy() {
    this.agents.destroy(); this.items.destroy(); this.gates.destroy();
  },
};
